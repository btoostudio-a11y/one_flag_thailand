# ADR-0002 — Guest เล่นได้ แต่คะแนนไม่ติด leaderboard จนกว่าจะ login

- **สถานะ:** รับ (Act mode — implemented)
- **วันที่:** 2026-09-15

## บริบท

ต้องการให้ผู้เล่น "ลองเล่น" ได้โดยไม่ต้องกรอกข้อมูล (friction ต่ำ) แต่เพราะมีรางวัลจริง
คะแนนของคนที่ยังไม่ login ต้อง**ไม่**ขึ้น leaderboard มิฉะนั้นจะเปิดช่องโกงแบบ
"เล่นเป็น guest หลายรอบสะสมคะแนน" แล้วค่อยมา login ทีหลัง

## การตัดสินใจ

ผู้เล่นที่ยังไม่ login (Guest) เล่นเกมได้จริง แต่เมื่อจบเกม:
- คะแนน **ไม่ถูกส่งขึ้น Supabase** และไม่ติด leaderboard
- หน้าผลลัพธ์จะ**ชวนให้ login** เพื่อเปิดสิทธิ์ "เก็บคะแนน" ในเกมถัดไป

กล่าวคือ "ถ้าต้องการเก็บ score ให้ login" และคะแนน guest ถูกทิ้งเมื่อจบเกม

## ทางเลือกที่พิจารณา

1. **Hard gate — บังคับ login ก่อนเข้าเล่น** — ยืนยันตัวตน 100% แต่ friction สูง
   คนอยากลองเล่นต้อง login ก่อน → ละทิ้งเพื่อ UX
2. **ผสานคะแนน guest เข้ากับบัญชี** — เป็นมิตรต่อผู้เล่น แต่เปิดช่องโกงมาก
   (guest สะสมได้) → ละทิ้งเพราะความปลอดภัยเรื่องรางวัล
3. **Guest เล่นได้ แต่ไม่ติด leaderboard (เลือก)** — สมดุล: คง UX ไว้ ขณะที่คะแนน
   ผูกกับตัวตนจริงเสมอ

## ผลที่ตามมา

- Client ตรวจ `is_logged_in()` ก่อนส่งคะแนน; ถ้าไม่ login ระบบจะไม่สร้าง
  submission ให้ (คะแนน guest ไม่ถูกบันทึกถาวร)
- ต้องมี UI ผู้อบรมให้ผู้เล่นรู้ว่า "login เพื่อเก็บคะแนน"
