# ADR-0003 — Best score ต่อคน 1 แถว + กติกา "ถึงก่อนชนะ"

- **สถานะ:** รับ (Act mode — implemented)
- **วันที่:** 2026-09-15

## บริบท

Leaderboard top-10 ที่แจกรางวัลต้องโปร่งใสและยุติธรรม ต้องตอบได้ว่า "ผู้ชนะคือใคร
และใครอยู่สูงกว่าเมื่อคะแนนเสมอกัน"

## การตัดสินใจ

ใช้หลัก:
- **คะแนนดีที่สุด (best score) ต่อ account 1 แถว** — ผู้เล่นคนเดียวขึ้น leaderboard
  ได้แถวเดียว ใช้คะแนนสูงสุดของตนเอง
- **กติกา "ถึงก่อนชนะ"** — เมื่อคะแนนเสมอกัน ผู้ที่ถึงคะแนนนั้น**ก่อน** (ตาม
  `achieved_at` timestamp) อยู่สูงกว่า ในตาราง Supabase ใช้ unique constraint
  บน `user_id` + เก็บแถวคะแนนที่ดีที่สุดพร้อม timestamp แรกสุดที่ทำได้

## ทางเลือกที่พิจารณา

1. **เก็บทุกคะแนน (หลายแถวต่อคน)** — เห็นประวัติการเล่น แต่คนเก่งคนเดียวอาจกวาด
   ทั้ง top-10 ทำให้รางวัลมุ่งไปที่คนเดียว → ละทิ้ง
2. **คะแนนเสมอ → ใช้สถิติอื่น (ธงไทย/คอมโบ) แยก** — ซับซ้อนและตีความยาก →
   ละทิ้ง
3. **เสมอกันจริง (แสดง rank เดียวกัน)** — จ่ายรางวัลไม่ชัดเจน → ละทิ้ง

## ผลที่ตามมา

- ตรรกะอัปเดต: แทรก/อัปเดตคะแนนก็ต่อเมื่อ score ใหม่ดีกว่าค่าที่เก็บไว้
  (กรณีคะแนนใหม่เท่าเดิม แต่ถึงก่อนหน้าครั้งเดิม → ไม่แทนที่ `achieved_at`)
- หน้า leaderboard แสดง ranking จากคะแนนดีที่สุดของแต่ละบัญชี
